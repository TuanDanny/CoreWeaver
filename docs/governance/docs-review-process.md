# Docs Review Process

## Before Work
- Read `AGENTS.md`.
- Read public docs plus local-only `_private/plans/` when available.
- Read relevant product spec.
- Read active exec plan if work is multi-step.

## During Work
- Update active plan checklist.
- Record decisions in docs, not chat only.
- Keep changes additive unless migration is approved.

## After Work
- Update indexes.
- Run docs health check.
- Add completion note or completed plan when scope is done.

## Required Review Questions
- Did docs change with behavior changes?
- Did tests change with contracts?
- Did prompt paths stay canonical?
- Did generated/manual indexes remain accurate?
