# Change Review Checklist

## For Feature Changes
- Identify task type from `AGENTS.md`.
- Read relevant design/product docs.
- Add or update active exec plan if work is multi-step.
- Update tests with behavior changes.
- Update docs if contracts changed.

## For Docs Changes
- Keep `AGENTS.md` concise.
- Prefer additive changes unless migration is approved.
- Avoid duplicate prompt sources.
- Use Markdown with YAML frontmatter.

## For Prompt Changes
- Check `docs/prompts/index.md`.
- Update prompt compliance docs/tests when applicable.
