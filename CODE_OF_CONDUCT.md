# Code of Conduct

CoreWeaver is a technical project for careful engineering work. Keep collaboration respectful, specific, and focused on making the system safer and easier to review.

## Expected Behavior

- Be direct, kind, and constructive.
- Critique code, contracts, and evidence rather than people.
- Keep security reports and private plans out of public channels.
- Respect project boundaries and reviewer decisions.

## Unacceptable Behavior

- Harassment, threats, or personal attacks.
- Publishing secrets, private plans, or sensitive artifacts.
- Intentionally bypassing safety, trace, replay, or handoff gates.

## Enforcement

The repository owner may edit, hide, close, or remove issues, pull requests, comments, or access that violates these expectations.
